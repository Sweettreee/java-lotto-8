# java-lotto-precourse

# 프로그램 설명

#### 1. 금액을 입력받아 구매 로또 갯수와 로또 당첨 결과 테이블을 생성한다

#### 2. 로또는 1 ~ 45범위의 중복되지 않은 숫자 6개로 구매 갯수만틈 생성한다

#### 3. 당첨 번호와 보너스 번호를 입력받는다

#### 4. 생성된 로또와 당첨번호 및 보너스 번호를 비교해 당첨 결과를 테이블에 업데이트한다

#### 5. 당첨 내역 및 수익률을 출력한다

## 계층별 책임

+ 2주차와 동일하게 TDD 방식과 MVC 디자인
+ support에 지원 메소드(난수 생성 및 파싱)

| 구조         | 책임          | 예시             |
|------------|-------------|----------------|
| Model      | 데이터 저장 및 검증 | 로또 및 결과 정보 저장  |
| Controller | 흐름 제어       | 입력->생성->계산->출력 |
| View       | 입출력         | Console 읽기/쓰기  |

## 프로그램 흐름도

``` text
[1] 금액 입력
└─> 금액 유효성 검증
├─ 실패: 다시 입력 및 ERROR 메시지 출력
└─ 성공: 다음 단계 진행

[2] 구매 로또 개수 및 로또 테이블 생성  
└─> 보상 기준표와 당첨 금액 결과표 생성

[3] 로또 번호 생성
└─> 난수로 로또 번호 생성
└─ 로또 번호 유효성 검증
├─ 실패: 다시 생성 및 ERROR 메시지 출력
└─ 성공: 로또 출력

[4] 당첨 번호 입력
└─> 당첨 번호 파싱 및 유효성 검증
├─ 실패: 다시 입력 및 ERROR 메시지 출력
└─ 성공: 보너스 번호 입력

[5] 보너스 번호 입력
└─> 보너스 번호 유효성 검증
├─ 실패: 다시 입력 및 ERROR 메시지 출력
└─ 성공: 수익률 계산 단계로 이동

[6] 로또 수익률 계산 및 저장  
└─> 당첨 종류별 결과 출력  
└─ 수익률 출력

[7] 프로그램 종료
```

## 로또 발매기 기능 정리

## 1. 로또

- [X] 로또 번호 `6`개를 저장한다
- [X] 발행한 로또 번호들을 `오름차순`으로 저장한다
- [X] 로또 번호가 정확하게 `6개`인지 검증한다
- [X] 로또 번호가 `1-45` 범위의 인지 검증한다
- [X] 로또 번호 6개가 `중복`되지 않았는지 검증한다

## 2. 랜덤 숫자 발생기

- [X] `1 ~ 45`의 `중복`되지 않은 `랜덤` 숫자 `6`개를 발생시킨다

## 3. 당첨 번호

- [X] `당첨 번호`와 `보너스 번호`를 저장한다
- [X] 당첨 번호가 `6`개인지 검증한다
- [X] 당첨 번호가 `1-45` 범위의 숫자인지 검증한다
- [X] 당첨 번호가 서로 `중복`되지 않았는지 검증한다
- [X] 보너스 번호가 `1-45` 범위의 숫자인지 검증한다
- [X] 보너스 번호와 당첨 번호가 `중복`되지 않는지 검증한다

## 4. 당첨 번호 파싱

- [X] 당첨 번호를 문자열로 받아 `파싱` 후 실패하면 `NumberFormatException`을 발생시킨다

## 5. 사용자 로또 현황

- [X] 금액을 받아 1000의 배수인지 `유효성`을 검증한다
- [X] 금액을 받아 음수인지 `유효성`을 검증한다
- [X] 금액을 받아 20억 미만인지 `유효성`을 검증한다
- [X] 금액을 받아 `구매 개수`를 반환한다
- [X] `보상기준표`와 사용자의 `당첨금액표`를 생성한다
- [X] `로또`를 받아 저장한다
- [X] 로또 금액과 당첨 번호를 받아 `당첨 여부` 및 `금액`을 계산한다
- [X] `당첨 횟수`를 계산한다
- [X] 당첨 금액을 받아 당첨 `기준별` `당첨 횟수`와 `금액`을 저장한다
- [X] `수익률`을 계산하여 저장한다

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

+ 로또 번호의 숫자 범위는 1~45까지이다.
+ 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
+ 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
+ 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.

| 등수 | 기준                | 상금             |
|----|-------------------|----------------|
| 1등 | 6개 번호 일치          | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
| 3등 | 5개 번호 일치          | 1,500,000원     |
| 4등 | 4개 번호 일치          | 50,000원        |
| 5등 | 3개 번호 일치          | 5,000원         |

+ 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
+ 로또 1장의 가격은 1,000원이다.
+ 당첨 번호와 보너스 번호를 입력받는다.
+ 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
+ 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
+ Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

## 입출력 요구 사항

- [X] 입력
- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

> 14000

- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

> 1,2,3,4,5,6

- 보너스 번호를 입력 받는다.

> 7

- [X] 출력
- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

```terminaloutput
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

- 당첨 내역을 출력한다.

```terminaloutput
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

> 총 수익률은 62.5%입니다.

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.

> [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
