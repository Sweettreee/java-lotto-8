# java-lotto-precourse

# 프로그램 설명
#### 1. 로또를 하나에 1,000원으로 구매한다
#### 2. 로또는 1 ~ 45범위의 중복되지 않은 숫자 6개와 보너스 숫자 1개를 뽑는다
#### 3. 숫자 6개와 보너스 숫자 1개를 보고 당첨 순위를 정한다
#### 4. 당첨 내역 및 수익률을 출력한다

## 로또 발매기 기능 정리

## 1. 로또
- [X] 로또 번호 6개와 보너스 번호 1개를 저장한다

## 2. 로또 발생기
- [X] 1 ~ 45의 중복되지 않은 숫자 6개와 보너스 번호 1개를 발생시킨다

## 3. 로또 검증기
- [X] 로또가 1 ~ 45의 자연수 7개를 정확하게 가지고 가지고 있는 지 검증
- [X] 로또 번호 6개가 중복되지 않았는지 검증

## 4. 당첨 번호
- [X] 당첨 번호를 저장한다

---

## 5. 로또 진행
- [X] 로또를 하나 받아 당첨 번호와 비교해 1 ~ 5등 흑은 낙첨을 결정한다

## 6. 사용자 로또 현황
- [X] 구매 개수를 저장한다
- [X] 발행한 로또 번호들을 오름차순으로 저장한다
- [X] 각 당첨 기준별 당첨 횟수와 금액을 저장한다
- [X] 수익률을 계산하여 저장한다

---

## 7. 금액 입력
- [X] 금액을 입력받습니다
- [X] 당첨 번호를 문자열로 입력받습니다
- [X] 당첨 번호 문자열을 `,`로 구분하여 값을 저장한다
- [X] 보너스 번호를 입력받는다

## 8. 금액 입력 검증기
- [X] 금액이 1,000의 배수인지 검증하여 실패하면 다시 입력받게 처리한다
- [X] 당첨 번호가 개수가 `6`개인지 검증한다
- [X] 당첨 번호가 `1~45`의 자연수인지 검증한다
- [X] 잘못된 값을 입력할 경우 그 경우에 맞는 `Exception` 발생 및 `ERROR`를 포함한 에러 메시지 출력 후 다시 입력받게 한다

## 9. 출력
- [X] 발행한 로또 수량 및 번호를 출력한다
- [X] 당첨 내역을 출력한다
- [X] 수익률을 출력한다
